# 04 · 移动端（Android v1 · iOS 以后）

原型：`prototype/mobile.html`，每个屏幕都把 Android（412×915 dp）和 iOS（393×852 pt）并排展示。
**同一套 Compose Multiplatform 代码**：内容区（消息、卡片、轨迹、图表）两端完全一致；只有**外壳**（状态栏、顶栏、底部导航、sheet、开关、返回手势）按平台变化，通过 `expect/actual` 的 `PlatformChrome` 实现。

## 1. Token 落地

- 颜色、圆角、间距与桌面相同，字号使用 `type.mobile`（正文 15，消息 16）。
- 不使用 Material You 动态取色。M3 `ColorScheme` 映射：`primary=accent`、`onPrimary=accent.on`、`surface=bg.window`、`surfaceContainer=bg.sidebar`、`surfaceContainerHigh=bg.elevated`、`outline=border.default`、`outlineVariant=border.subtle`、`error=danger`。
- 半透明模式：顶栏、底部导航、sheet 用模糊 30（Android 12+ 支持；更低版本退回不透明）；iOS 用 `.ultraThinMaterial`。

## 3. 信息架构

底部 3 个标签：**消息 · 工作台 · 我的**（DESIGN.md §5）。
- 消息：Host 切换（Android 放在顶栏标题里；iOS 放在大标题下方的一行 13pt）→ 主 Bot（固定在顶部，`bg.selected` 底色）→「群」→「已完成 N ›」→「Bot」。
- 工作台：分段控件（铺满宽度，高 30）→ 两条横幅 → Bot 卡片。
- 我的：Host 卡片 → 分组列表（仪表盘、Bot 管理、技能、定时任务）→（外观、通知、关于）。分组列表的行高：Android 56，iOS 48。

## 5. 手势与反馈

| 手势 | 行为 |
|------|------|
| 长按消息 | 触感反馈（Android `LONG_PRESS`，iOS `.medium`），背景压暗，消息浮起 scale 1.02，显示表情行加动作 sheet |
| 向右滑消息 | 回复（拖动超过 56 时触发，同时触感反馈） |
| 下拉列表 | 刷新（实际上是触发重连 / 补发） |
| 双击消息 | 👍 回应 |
| 状态变化 | 不做额外的触感反馈；只有 ⚠ 需要你的时候，在前台也弹出一条顶部横幅（Android Snackbar，iOS 应用内 banner），4 秒后消失 |
