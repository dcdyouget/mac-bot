# 03 · macOS 客户端

原型：`prototype/mac.html`（顶部可以切换 55 个屏幕）。产品行为见 `docs/DESIGN.md` 第 4 章，本文只规定视觉和尺寸。

## 1. 窗口

| 项 | 值 |
|----|----|
| 默认尺寸 / 最小尺寸 | 1280 × 820 / 960 × 600 |
| 栏宽比例 | **侧栏 260 · 列表栏 260 · 右面板 280**。凡是「列表 + 详情」的页面（技能、定时任务、设置、产物预览），中间的列表栏都是 260，和侧栏一样宽 |
| 圆角 | 12（系统决定）|
| 标题栏 | 透明的统一标题栏，**高 52**；没有单独的标题栏，三栏的顶部区域就是标题栏 |
| 红绿灯 | 左上 (20, 18)，间距 8，直径 12；侧栏顶部左边留出 88 |
| 拖动区域 | 三栏顶部 52 高的空白部分 |
| 外观 | 设置里可选：浅色 / 深色 / 跟随系统；「半透明材质」开关（默认打开） |

## 2. 三栏

```
| 侧栏 260 (220–320) | 会话区 ≥480，消息列 ≤760 居中 | 右面板 280 (260–360) |
```

- 分隔线 1px `border.subtle`；在分隔线左右 4px 范围内可以拖动，悬停时光标变为 col-resize，同时分隔线变为 `accent`。
- 宽度 < 1100 时，右面板自动收起为覆盖层（从右侧滑入，e4，遮罩为透明）；宽度 < 820 时，侧栏也收起为覆盖层。
- `⌘\` 收起侧栏，`⌘⇧\` 收起右面板，动画 200ms standard。
- 半透明：侧栏和右面板用模糊 40；会话区工具栏用模糊 24；消息流底色 86% 不透明。

## 4. 会话区

### 4.1 工具栏（高 52）
左内边距 16，右 12；底色 `bg.window`（半透明模式模糊 24）；下边 1px `border.subtle`。
- 私聊：头像 32 + 名字 14/600 + 副标题 11 `text.secondary`（主 Bot：「主 Bot · 只协调，不干活」；Bot：「写代码、部署 · 工作中 2 个活」）。右侧：搜索、右面板开关。
- 群：群头像 32 + 群名 + 副标题「4 位成员 · [● 进行中] chip」。

### 4.2 群状态条（高 36）
内边距 6 16，成员 chip（见 02 §3）间距 4；点某个 chip 就在右面板打开该成员的工作详情。横向放不下时，可以横向滚动，并在右边缘做 24px 渐隐。

### 4.3 公告条（高 40）
内边距 0 16；左侧 2×24 `accent` 竖条（Telegram 置顶消息样式）；「公告」12/600 `accent`；下一行是**公告 Markdown 的纯文本摘要**（去掉格式后的前 80 字），12 `text.secondary`，单行省略；右侧 chevron。点击后在右面板打开公告。

### 4.4 消息流
见 02 §5–7。底色 `bg.chat`。滚动条：6px 宽，滚动时才显示，`border.strong`。新消息到达且当前不在底部时，右下角显示 40×40 圆形「↓ N」按钮（e3，`bg.elevated`）。

### 4.5 输入框
见 02 §9。草稿按会话保存；断线时禁用。

## 5. 右面板（280）

- 页头高 52：左内边距 16，右 12；标题 13/600；右侧有 ⚙（打开 Bot / 群设置）和收起按钮。页面栈有上一页时，最左边显示 ‹ 返回。页面切换时，新页从右侧推入 24px 并淡入，200ms。
- 内容：内边距 12 16 24；分区之间间距 20；分区标题高 20，11/600 `text.tertiary`，右侧放数量或操作。
- 键值：两列网格，键列宽 56，行距 6，13/18。

**右面板只放两类内容：正在跟进的事，以及当前对话里等你处理的事**。不放今日统计，也不放定时任务（定时任务有单独的页面）。

| 会话 | 右面板 |
|------|--------|
| 主 Bot 私聊 | ①「本对话中等你处理」：本对话里的验收、提问（横幅样式，点击后滚动到对应卡片）；②「正在跟进的群」：每行 52 高，群头像 32 + 群名 + 状态 chip + › 进入群聊 |
| Bot 私聊 | ①「本对话中待审批」：横幅 + [处理]；②「正在干的活 N/上限」：每个任务一张小卡片（spinner + 群名 · 任务名 + 用时和 token + [群聊] [详情]），下面是排队提示 |
| 群 | ① **公告**：一段由总管维护的 Markdown 文本，按 Markdown 渲染（h3 14/600，正文 13/20，列表左缩进 18，行内代码同气泡），放在一张卡片里（内边距 12 14）；分区标题右侧显示「10:32 更新」；卡片下方是 [打开 Home] [复制路径]。**不使用固定字段**（目标、截止时间等都写在 Markdown 里），**也没有「流程」**，因为一个群会先后处理多件事。② 成员与状态。③ 产物。点任务详情或成员时，压栈显示工作详情 |

**群公告中的产物**：每行显示 28 的图标块 + 名称 + **作者标签**（高 18、圆角 9、`bg.active` 底，里面放 16 的头像 +「产品 提供」11px）+ 路径（mono 11）+ 更新时间 + 右侧 [预览] secondary sm。点 [预览] 打开产物预览页（§6）。

**工作详情（面板版）**：顶部头像 28（工作中带外圈）+ 任务名 15/600 + 11px 元信息；操作按钮 [停止] danger sm、[@ 它]、[屏幕]；「任务指令」卡片（插话行前面加 `warning` ✎）；「工作过程」每步 28 高：✓ / spinner 14 + 工具图标 14 `text.tertiary` + 文字 + 右侧结果 11px；运行中的步骤下面接终端块；底部是 [思考摘要 ›] [完整记录 ›]。

## 6.2 `/` 呼出技能列表

| 状态 | 规格 |
|------|------|
| 触发 | 输入框为空、或光标前是空格 / 行首时输入 `/`，立即弹出；继续输入即筛选（匹配技能名的子串，命中部分加粗为 `accent`）。删掉 `/` 或按 Esc 关闭 |

| 列表项 | 最小高 48，圆角 8：28 的图标块（`accent.soft` 底，zap 图标）+ `/名称`（mono 12.5 / 500）+ 描述（12，单行省略）+ 右侧来源与次数（11 `text.tertiary`）。选中项：`accent` 底、`accent.on` 文字 |

| 发出后 | 气泡开头显示同样的技能标签（我的气泡里底色为 16% 强调色）；插话的送达状态追加「已加载技能 xx」 |

协议：发送时 `text` 以 `/<技能名>` 开头（PROTOCOL 5.2「强制使用技能」），客户端只负责把标签序列化成这个前缀。

## 6.3 引用回复与决策（原型 `#reply` `#decide1–3` `#single`）

- **右键消息**：弹出菜单（宽 236，e3，出现在指针处，自动避让窗口边缘）：顶部一行 6 个常用表情（30×30），分隔线，然后是 回复 R · 引用 Q · 复制文字 ⌘C · 引用到公告 · 查看工作详情 · 复制消息链接；自己的消息多一项红色的「删除」。被右键的消息外圈加 2px `accent.soft` 描边，直到菜单关闭。
- **回复与引用**：右键 →「回复」/「引用」，或悬停工具条的 ↩、焦点在消息上按 R / Q→ 输入框上方出现回复条（高 44，圆角 12，与输入框同宽，间距 6）→ 发送后气泡顶部带引用块。规格见 06 #3。
- **决策**：选项就在 Bot 的消息里，选完原地变成已回答的样子；多题时堆叠显示，答完后用题号标签切换查看。规格见 06 #5、#5a。键盘：焦点在决策卡片上时，1–9 选择选项，←→ 切换题目，O 打开「其他，我来说…」。

## 6.4 待看消息（不打断正在干活的 Bot）

规则：只有 **@ 某个 Bot** 或 **回复它的消息** 才会打断它（下一步生效）；其余消息进入它的「待看消息」，交付前一起查看。原型 `#queue` `#queuepanel` `#queuedone`。

| 位置 | 规格 |
|------|------|
| 输入提示 | 群里有 Bot 正在干活、而输入框里的内容**没有 @ 任何人**时，输入框上方出现提示条（与回复条同样式：圆角 12，与输入框同宽，间距 6）：时钟图标 `accent` +「**编码** 正在干活，这条消息不会打断它，会在交付前看到」+ 每个干活的 Bot 一个 [@编码 立即生效] 按钮（高 26），点击后在输入框开头插入 @。输入了 @ 或清空输入后提示消失 |
| 送达状态 | 发出后，气泡下方：「总管 已收到 · ◷ 编码 交付前会看到」（后半段 `accent`）→ 编码交付前看过后变为「编码 交付前已查看 ✓」（`success`） |
| 状态条 | 正在干活的成员 chip 后面加待看数：高 16、圆角 8、白底描边的小标（时钟 + 数字） |
| 工作详情 | 「任务指令」和「工作过程」之间新增分区「待看消息 N」：每条一张小卡片（发送者 + 时间 + 最多 2 行正文 + 右上角 [改为插话] ghost，点击后这条立即作为插话，下一步生效）；已查看的透明度 0.6 并标「✓ 已查看」；分区底部 11px 说明 |
| 工作台 | 任务名后面显示「◷ 待看 N」小标 |
| 运行轨迹 | 交付前多一条记录「◷ 交付前查看新消息 N 条」（图标块用 `warning.soft`），展开后每条一行「原文 → 处理结果」 |

## 6.5 提示音

所有通知和应用内提示只用一个声音「啵啵 · 气泡」（`design/sounds/04-bubble-pop.m4a`），规则见 01 §11。设置 → 通用 → 通知分组里加一行「提示音」开关（默认开）。

## 7. 交互细节

| 交互 | 规格 |
|------|------|
| 切换会话 | 消息区直接替换，不做动画；记住每个会话的滚动位置 |
| 新消息 | 淡入 + translateY 4→0，120ms；如果当前在底部，自动滚动到底，200ms |
| 状态变化 | chip 颜色和图标交叉淡入淡出，120ms；侧栏排序变化时，行的位置 200ms 平移 |
| 悬停 | 背景 80ms；工具条 300ms 后出现，离开后 100ms 消失 |
| 右键 | 原生 NSMenu 样式（系统菜单） |
| 拖入文件 | 会话区整体显示 2px `accent` 虚线框 + `accent.soft` 遮罩，中间提示「松开发送给 编码」 |
| 跟随最新 | 轨迹自动滚到底；用户向上滚动超过 40px 时自动关闭，按钮变成「↓ 回到最新」 |
