# 01 · 设计基础

所有数值的权威来源是 `tokens.json`，本文解释**为什么这样定**以及**怎么用**。单位：桌面为 px（= macOS pt），移动端为 dp / pt（原型中 1:1 绘制）。

## 1. 原则

1. **内容是主角**：界面色彩接近无彩色，只有状态和操作用颜色。一屏里饱和色面积不超过 5%。
2. **素雅**：中性灰微微偏暖（浅色）或微微偏冷（深色）；强调色是低饱和的**石板蓝** `#4A6A9B`，语义色都降低了饱和度。
3. **原生感**：系统字体、系统控件尺寸（28 / 24 / 36 按钮，32×18 开关），macOS 用 vibrancy，iOS 用 material，Android 遵守 M3 的结构尺寸。
4. **一眼知道谁在干活**：状态的形状和颜色在三端完全一致（见 §3.3）。
5. **聊天就是聊天**：消息区按 Telegram 的习惯来，用户不需要学新东西。

## 2. 三种外观

| 模式 | 触发 | 说明 |
|------|------|------|
| 浅色 `light` | 跟随系统 / 手动 | 默认 |
| 深色 `dark` | 跟随系统 / 手动 | 不是纯黑：窗口 `#18181A`，聊天区 `#111113`，层级靠亮度区分 |
| 半透明 `translucent` | 设置 → 外观 →「半透明材质」开关，**可以和浅色或深色叠加** | 侧栏、右面板、工具栏、弹层透出桌面；聊天区和轨迹保持 86% 不透明，保证可读 |

**半透明规则**
- 只改变 `bg.window / sidebar / panel / chat / elevated / input` 的 alpha，其余 token 不变。
- 模糊：侧栏 40px、面板 40px、工具栏 24px、弹层 30px，饱和度 ×1.8。
- macOS（Tauri）：窗口用 window-vibrancy 设置原生毛玻璃（`NSVisualEffectView`），各表面再用 CSS `backdrop-filter`（同时写 `-webkit-` 前缀）；系统开启「降低透明度」时，**自动退回不透明**。
- iOS：导航栏、标签栏、sheet 使用 `.ultraThinMaterial`；Android 12+ 用 `RenderEffect.createBlurEffect`，更低版本退回不透明。
- Web 管理页不提供半透明模式（只有浅色和深色）。

## 3. 颜色

### 3.1 表面层级（从后往前）

| Token | 浅色 | 深色 | 用在哪里 |
|-------|------|------|----------|
| `bg.desktop` | `#E9E8E4` | `#0B0B0C` | 原型背景（产品里不用） |
| `bg.sidebar` | `#F3F3F1` | `#141416` | 左侧栏、移动端底栏 |
| `bg.panel` | `#F7F7F5` | `#1A1A1D` | 右面板、设置导航、技能列表 |
| `bg.window` | `#FBFBFA` | `#18181A` | 工具栏、非聊天页面主区、移动端页面 |
| `bg.chat` | `#EFEFEB` | `#111113` | **消息流背景**（Telegram 式：比气泡暗一档，让白气泡浮起来） |

| `bg.input` | `#FFFFFF` | `#1F1F22` | 输入框 |

交互叠加层（盖在任意表面上）：`bg.hover` 4.5% / 5%，`bg.active` 7.5% / 8%，`bg.selected` = 强调色 12% / 16%，`bg.overlay`（遮罩）28% / 50%。

分隔线：`border.subtle` 6%（区域分隔、列表分隔）、`border.default` 10%（输入框、按钮描边）、`border.strong` 18%（复选框、关闭的开关）。**所有分隔线 1px**；iOS 列表分隔线 0.5pt。

## 5. 间距

4 基数：`2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64`（token `space.1…12`）。

常用组合：
- 控件内部图标与文字：6
- 列表行左右内边距：8（桌面侧栏）/ 16（移动端、右面板）
- 卡片内边距：12×14（紧凑）/ 16（常规）/ 24（Web）
- 区块之间：20（面板分区）/ 24（页面分区）/ 40（Web 大区块）
- 同一发送者的连续消息：2；不同发送者：10；日期胶囊上下 12

## 7. 阴影（elevation）

| 级别 | 值 | 用途 |
|------|----|------|
| e0 | 无 | 列表、气泡（气泡只有 `0 1px 1px rgba(0,0,0,.04)`） |
| e1 | `0 1px 2px rgba(0,0,0,.06)` | 卡片、白色按钮、输入框 |
| e2 | `0 2px 8px shadow + 0.5px border.subtle` | 悬停工具条、浮起的预览 |
| e3 | `0 8px 24px shadow + 0.5px border.default` | 弹出菜单、@ 列表、FAB |
| e4 | `0 20px 60px shadow + 0.5px border.default` | 对话框、sheet、⌘K |

`shadow.color`：浅色 `rgba(20,20,24,.10)`，深色 `rgba(0,0,0,.45)`。深色模式主要靠 0.5px 描边区分层级。

## 8. 动效

| Token | 时长 | 缓动 | 用途 |
|-------|------|------|------|
| `instant` | 80ms | standard | 悬停背景、按下 |
| `fast` | 120ms | decelerate | 新消息淡入（同时 translateY 4→0）、chip 状态切换 |
| `normal` | 200ms | standard | 面板推入 / 推出、开关、分段控件滑块 |
| `slow` | 320ms | spring 380/34 | sheet、对话框出现（scale .96→1 + 淡入）、页面切换 |
| 转圈 | 1000ms linear ∞ | — | chip 中的 spinner；头像外圈 1200ms |
| ✓ 完成 | 600ms | — | 头像右下角绿点出现后停留 2s，再 200ms 淡出 |

`standard = cubic-bezier(.2,0,0,1)`，`decelerate = (0,0,0,1)`，`accelerate = (.3,0,1,1)`。系统开启「减弱动态效果」时：转圈改成静态的 ⟳ 图标，所有位移动画改成 120ms 淡入淡出。

### 8.1 灵动（v1.2，参考 Apple 信息与 Grok Bot）

| Token | 值 | 用途 |
|-------|----|------|
| `ease.spring` | `cubic-bezier(0.34, 1.36, 0.64, 1)`，带轻微回弹 | 新消息进入、Tapback、选项选中、开关滑块、弹层出现 |
| `ease.spring.soft` | `cubic-bezier(0.22, 1.12, 0.5, 1)` | sheet 上滑、消息列表整体进入 |
| `duration.spring` | 360ms | 回弹类动画的统一时长 |

| 交互 | 动效 |
|------|------|
| 新消息进入 | 别人的：自下方 10px 上移 + 0.98→1 缩放 + 淡入；我的：从右下（输入框方向）8px/10px 移入 + 0.96→1；`spring.soft` 360ms |
| 按压 | 所有按钮、选项、会话行、发送键按下时缩到 0.97，松开回弹 |
| 发送键 | 输入框从空到有内容时，发送键以 0.6→1 弹出（`spring`），并带一圈 `ring.focus` 外光 |
| Tapback | 0.6→1 弹出 |
| 弹层 / 对话框 / 悬停工具条 | 0.94→1 + 上移 4px + 淡入，`spring` 200–360ms；sheet 自下方 40% 上滑 |
| 卡片悬停 | 群聊卡片、产物行上移 1px |
| 正在输入 | 三个点依次上跳 4px 的波浪 |
| 减弱动态效果 | 全部动画缩短到 1ms（只保留结果，不保留过程） |

## 10. 豆豆头像

- 圆形底色 = `avatar.0…9`（低饱和：`#7C93B8 #86A894 #C6A47E #A08DBF #C48A8A #7FA9AE #B5A36C #9B9B9B #C49AB0 #8C9BC4`），底部有 2px 内阴影 `rgba(0,0,0,.08)` 表现体积。
- 眼睛：两个竖椭圆，颜色 `#1C1C1E`，各宽 12%、高 18%，中心分别位于 x = 38% 和 62%，顶边在 y = 40%。
- 主 Bot：戴**黑框眼镜**（秘书形象），颜色 `avatar.glasses` `#1C1C1E`。在 100×100 的坐标系里：两片镜框为 25×22 的圆角矩形（圆角 7），位置在 (24,37) 和 (51,37)；镜片填充 `rgba(255,255,255,.22)`；鼻梁是 (49,45)→(51,45) 的一段小弧；镜腿从 (24,44) 到 (12,41)、从 (76,44) 到 (88,41)；线宽 5（随头像缩放）。所有尺寸都画眼镜。
- 状态点：直径 30%（最小 8），放在右下角向外偏 1px，2px 描边，颜色取所在表面（侧栏上就是 `bg.sidebar`）。
- 工作中外圈：向外 3px，1.5px 线，`accent`，只画上方和右侧两段弧，1200ms 转一圈。
- 群头像：30% 圆角方形，底色 `bg.active`，内边距 3（32 尺寸时为 2），2×2 网格，间距 1：2 人放对角线，3 人时第三个居中放在第二行，4 人填满。
- 尺寸：20（侧栏 Bot 行、chip）、24、28（面板）、32（消息、工具栏）、40（侧栏会话）、48 / 52（移动端列表）、64 / 96（欢迎页、Bot 设置）。

## 11. 提示音

**三端只用一个提示音：「啵啵 · 气泡」**，文件 `design/sounds/04-bubble-pop.m4a`（另有 `.wav` 源文件）。

| 项 | 值 |
|----|----|
| 声音 | 两个极短的上行音（G6 → C7），柔和正弦音色，原创合成，无版权限制 |
| 时长 / 大小 | 150 ms · m4a 约 5 KB |
| 生成方式 | `python3 design/tools/make_sounds.py`（参数在脚本里，改音色只改脚本） |
| 用在哪里 | macOS 和手机的**所有**通知与应用内提示：新消息、需要你（审批 / 提问 / 接管）、待验收、任务完成。不同类型的区别靠通知内容和图标，不靠不同的声音 |
| 什么时候响 | ① 系统通知弹出时；② 应用在前台、但收到的消息**不在当前打开的会话**里时。当前正在看的会话来新消息**不响** |
| 防打扰 | 1 秒内多条只响一次；会话静音或通知关闭时不响；遵守系统的勿扰 / 专注模式 |
| 音量 | 文件峰值 -7 dBFS，播放时使用系统通知音量，不单独放大 |
| 平台落地 | macOS：`UNNotificationSound(named:)`，文件放进 app bundle 的 `Sounds/`（转成 `.caf` 或直接用 m4a）；应用内用 `NSSound`。Android：通知渠道（NotificationChannel）的声音设为 `res/raw/bubble_pop`，每个渠道都用同一个文件；应用内用 `SoundPool`。iOS（以后）：同 macOS，放进 bundle 并用 `UNNotificationSound` |
| 设置项 | 设置 → 通用 / 外观与通知 → 「提示音」开关（默认开）。不提供换声音的选项 |
