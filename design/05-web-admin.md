# 05 · Web 管理页（`/admin`，服务端内置）

原型：`prototype/web.html`。行为见 DESIGN.md §6：只负责首次设置密码、查看状态、修改端口和名称、查看日志、重启服务，**不提供业务配置**。

## 1. 技术约束
- 一个 HTML + 生成的 `tokens.css` + 少量原生 JS，用 `rust-embed` 嵌入；不使用框架，不加载外部字体或 CDN。
- 主题跟随 `prefers-color-scheme`，右上角可以手动切换；**没有半透明模式**。
- 支持 ≥ 360 宽：宽度 < 720 时，指标卡变为 2 列，键值行变为上下排列。

## 2. 布局

| 区域 | 规格 |
|------|------|
| 页头 | 高 56，下边 1px `border.subtle`；内容最大宽 880，左右内边距 32；Logo 28×28 圆角 8 `accent` + 「Mac Bot 管理」15/600 + Host 名 `text.secondary` + 版本 chip；最右边 [退出] ghost |
| 内容 | 最大宽 880 居中；上内边距 32，下 48 |
| 指标卡 | 4 列，间距 16，下外边距 24；内边距 16 20；标签 12 `text.secondary`，数值 22/600，说明 11 |
| 卡片 | 圆角 12，1px `border.subtle` + e1，卡片间距 24；卡片头高 52，左右内边距 24，15/600，下边分隔线；卡片体内边距 20 24 |
| 键值行 | 两列 `120 / 1fr`，最小高 44，14px；行间 1px 分隔线；键为 `text.secondary` |
| 操作行 | 内边距 16 24，上边分隔线，按钮右对齐，间距 8 |
| 日志 | 卡片头右侧：分段控件（全部 / 警告 / 错误）+ [● 实时]；日志区**两种模式都用深色底** `#141416`，mono 12/20，内边距 14 18，高 260（可以拖动调整）；时间 `#66666B`，WARN `#DDAA5C`，ERROR `#E08470` |

## 3. 首次设置页
- 全屏 `bg.sidebar`；中间卡片宽 420，内边距 32。
- Logo 48（圆角 12）→ 标题 22/700 → 说明 14 `text.secondary`（下外边距 24）→ 两个 lg 输入框（间距 16）→ 强度条（4 段，每段高 4，间距 6；用 `danger` / `warning` / `success` 表示强度）→ [完成] lg 铺满宽度 → 提示卡片（`bg.chat`，内边距 12 14，包含行内代码 `IP:7788`）。
- 两次密码不一致：确认框描边变为 `danger`，下方 11px 错误提示。

## 4. 状态
- 「运行中」为 `success` 点；「重启中」为 `warning` spinner，页面每秒轮询，恢复后 toast「已重启」。
- 保存端口后：弹出确认对话框「端口改为 7790 后，客户端需要用新地址重新连接」。
