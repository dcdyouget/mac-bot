# Mac Bot 设计文档 v1.1（组件、界面与交互）

> 状态：设计稿，尚未编码。本文回答三个问题：系统分成哪些组件、每个组件提供哪些界面和功能、界面长什么样。
> 架构、数据模型和里程碑见 [PLAN.md](PLAN.md)。两份文档有冲突时，**界面和交互以本文为准，后端实现以 PLAN.md 为准**。
> 视觉和交互参考 Grok Bot 的官方截图与文档（见附录 A）。

## 0. 一页总览

```text
    ┌──────────────────────────── Bot 主机（你的 Mac mini） ─────────────────────────────┐
    │ macbotd（无界面守护进程，一个端口 7788，一个访问密码）                             │
    │  ├ Gateway        /ws  /api/v1  /admin                                             │
    │  ├ Bot Runtime    每个 Bot 一个 actor：私聊、任务、工具、审批                      │
    │  ├ Orchestrator   ★ 群聊路由、@、交接、Bot 间私信、防循环                          │
    │  ├ Memory         用户画像 / 项目记忆 / Bot 笔记 + 全文检索                        │
    │  ├ Providers      自定义模型（OpenAI 兼容 / Anthropic / Google …）                 │
    │  ├ Scheduler      定时任务                                                         │
    │  ├ Browser        agent-browser sidecar：每个 Bot 一个浏览器会话 + 画面流          │
    │  ├ Store          SQLite                                                           │
    │  ├ Admin Web      /admin 极简管理页                                                │
    │  └ CLI            macbot status | passwd | logs | restart                          │
    └──────────────────────────────────────────┬─────────────────────────────────────────┘
                                               │ ws(s)://host:7788 + 密码
                  ┌────────────────────────────┼───────────────────────────┐
                  │                            │                           │
      桌面客户端（macOS，GPUI）         Android 客户端                iOS 客户端
              完整功能                    └─ Compose Multiplatform，同一套代码 ─┘
```

| # | 组件 | 运行在哪里 | 形态 | 用户能看到的界面 |
|---|------|-----------|------|------------------|
| 1 | **macbotd 服务端** | Bot 主机（Mac） | 无界面守护进程 | 无（通过客户端操作） |
| 2 | **Web 管理页** | 服务端内置 | 浏览器打开 `/admin` | 首次设置密码、运行状态、端口、日志、重启 |
| 3 | **CLI `macbot`** | Bot 主机终端 / SSH | 命令行 | `status` / `passwd` / `logs` / `restart` |
| 4 | **桌面客户端** | 任意 Mac | GPUI App | **全部功能**（第 3 章） |
| 5 | **移动客户端** | Android / iOS | Compose MP App | 对话、群聊、审批、实时画面和接管、查看定时任务（第 4 章） |
| 6 | **agent-browser** | Bot 主机 | sidecar 进程 | 无（它推送的画面显示在客户端的 Agent Computer 里） |

## 1. 核心概念（界面里出现的名词）

| 名词 | 含义 | 界面上的体现 |
|------|------|-------------|
| **Host** | 一台运行 macbotd 的 Bot 主机 | 侧栏左上角的 Host 切换器 |
| **Bot** | 有名字、头衔、长期规则、模型的 AI 同事，有自己的工作间 | 头像 + 名字 + 头衔 |
| **私聊** | 你和一个 Bot 的一对一会话 | 侧栏里的单头像条目 |
| **群聊** ★ | 你和 2–6 个 Bot 的会话；有群目标、负责人，可以绑定一个项目 | 侧栏里的叠放头像条目 |
| **负责人** | 群里当前对任务负责的 Bot，交接时会变更 | ★ 标记 |
| **交接（Handoff）** | Bot 把任务的负责权交给另一个 Bot | 群消息流里的「⇄ 交接」卡片 |
| **Bot 间私信** | Bot 之间的异步消息，你可以看到 | 「✉ A 私信了 B」卡片，Bot 详情里的「Bot 间对话」 |
| **项目** | 一个共享记忆空间；内置「全局」项目 | `# 项目名` 标签，Projects 页 |
| **当前项目** | 当前会话加载的是哪个项目的记忆。群聊由绑定决定，私聊可以切换 | 私聊顶部的 `# 项目 ⌄` |
| **群备忘** | 群里形成的决议和约定，所有成员共享 | 群信息面板，「✎ 记入群备忘」 |
| **话题段** | 一个会话被切成多段；切换项目、压缩、开始新话题时分段，旧段收敛成摘要 | 「─── 已切换到… ───」分隔线 |
| **上下文用量** | 这个会话下一轮要送给模型多少内容 | 顶部的 ◔ 42% |
| **屏幕** | Bot 自己的浏览器会话，也就是 Agent Computer | 右侧面板的缩略图，展开后是实时画面 |
| **定时任务（Routine）** | Bot 按计划自动执行的工作 | ◷ 图标 |
| **技能（Skill）** | 可复用的做事说明 | 输入框里用 `/` 引用 |
| **注意力状态** | 运行中 ⟳ / 等你 ⚠ / 未读 ● / 出错 ✗ | 侧栏条目右侧 |

## 2. 设计语言（从 Grok Bot 截图提炼）

**整体风格**：浅色、留白多、贴近 macOS 原生；内容是主角，装饰尽量少。三栏布局，各栏之间用细分隔线。

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| `bg.window` | `#FFFFFF` | `#1C1C1E` | 主区背景 |
| `bg.sidebar` | `#F5F5F7` | `#232325` | 侧栏、右侧面板 |
| `bubble.bot` | `#EFEFF1` | `#2C2C2E` | Bot 消息气泡 |
| `bubble.user` | `#111111`，白字 | `#F2F2F2`，黑字 | 用户消息气泡（**反色**，Grok 风格） |
| `text.primary` / `secondary` | `#1D1D1F` / `#86868B` | `#F5F5F7` / `#98989D` | 正文 / 次要信息、时间 |
| `accent` | `#2F7BF6` | `#4C8DFF` | 链接、未读点、「更多未读」按钮 |
| `success` | `#34C759` | 同左 | 定时任务图标、运行成功 |
| `attention` | `#FF9F0A` | 同左 | 「等你」状态、审批 |
| `danger` | `#FF3B30` | 同左 | 出错、删除、拒绝 |
| `code` | `#D63A5B` 等宽字 | `#FF6B8A` | 行内代码 |

- **字体**：系统字体（SF Pro / PingFang SC）。正文 14，次要信息 12，标题 15 半粗。代码用 SF Mono。
- **圆角**：气泡 18，卡片 14，输入框 22（胶囊形），头像为圆形。
- **间距**：4 / 8 / 12 / 16 / 24。消息之间 6；同一个人的连续消息合并头像，间距缩小为 2。
- **图标**：Lucide（gpui-kit 自带）。
- **Bot 头像「豆豆」**：彩色圆形豆子加两只眼睛（与 Grok 的小怪物风格类似，但造型不同），有 10 种预设颜色。也可以换成 emoji 或上传图片。群聊头像由成员头像叠放而成（最多显示 3 个）。
- **动效**：运行中的 Bot 头像外圈转动；新消息淡入 120ms；面板切换滑动 200ms。
- **深色模式**：跟随系统，也可以手动切换。

### 3.2 侧栏

| 元素 | 交互 |
|------|------|
| **Host 切换器**（左上） | 显示当前 Host 名称和在线点（绿色在线，灰色离线，黄色重连中）。点开后列出所有 Host、「添加 Host…」「管理 Host…」。切换后整个界面换成那台 Host 的数据。 |
| **＋ 新建**（`⌘N`） | 打开「新建对话」面板（3.6） |
| **搜索**（`⌘K`） | 打开搜索面板（3.10） |
| **置顶 Bot 磁贴** | 最多 6 个大头像，下面是名字和头衔。点击打开私聊，拖动可以排序 |
| **会话列表** | 私聊和群聊混排，按**用户自定义分组**显示（例如「内容」「群聊」「运维」，没分组的放在「未分组」）。每一条显示头像、名字、最后一条消息预览、时间，以及注意力状态 |
| 右键菜单 | 置顶、移动到分组…、重命名（群）、隐藏、通知开关、删除 |
| **隐藏的 Bot（N）** | 展开后显示被隐藏的 Bot。隐藏的 Bot 仍在运行，它的定时任务也不会停 |
| 底部 | ▤ 项目、ϟ 技能、⚙ 设置 |
| 「↓ 更多未读」浮动按钮 | 列表下方还有未读时出现，点击滚动过去 |

**注意力状态的优先级**：⚠ 等你（需要审批或回答）> ✗ 出错 > ⟳ 运行中 > ● 未读 > 时间。

### 3.3 会话区：消息类型

| 类型 | 样式 | 说明 |
|------|------|------|
| 用户消息 | 右对齐，黑色胶囊气泡（深色模式下反色） | 支持图片、文件、链接 |
| Bot 消息 | 左对齐，浅灰气泡；渲染 Markdown（标题、列表、代码、表格、链接） | 群聊里，同一个 Bot 的一串连续消息上方显示**头像、名字和头衔** |
| 日期分隔 | 居中灰字，例如「今天 13:00」 | 间隔超过 15 分钟时插入 |
| 系统事件 | 居中灰字 | 例如「已重命名为 Arnold」「负责人变更为 Editor」「Analyst 加入了群聊」 |
| **分段线** | 「─── 已切换到项目 # 周报 · 开始新话题段 ───」，下方附「上一段摘要… 展开」 | 切换项目、开始新话题、压缩时出现 |
| **记忆提示** | 小号行「✎ 记住了：…  撤销」 | Bot 每次写入记忆都会显示；群里写群备忘也一样 |
| **工具活动** | 可折叠的卡片「工具活动 · 浏览 x.com（6 步）▸」 | 展开后逐步显示工具名、参数摘要、耗时和结果 |
| 截图 / 图片 | 缩略图网格，点击放大 | 来自浏览器截图或 Bot 生成的图片 |
| **任务卡片** | 标题 + 状态（⟳ 运行中 / ✓ 完成 / ✗ 失败）+ 操作按钮 | 长任务的进度；按钮例如「查看屏幕」 |
| **提问卡片** | 问题 + 带字母编号的选项（A/B/C），可以「其他…」自由输入，右上角 ✕ 跳过 | 选择后折叠成一行「✓ 你选择了 B」 |
| **审批卡片** | 「需要审批 · 工具名」+ 具体内容（如完整命令）+ [允许一次] [总是允许] [拒绝] | 只出现在**私聊**里。处理后折叠成「✓ 已允许一次」 |
| 草稿卡片 | 可编辑的草稿 + [发送] [丢弃] | 对外发出的内容，例如发帖、邮件 |
| 文件卡片 | 文件图标、名称、大小，[打开] [保存] | 文件位于 Bot 工作间或共享目录 |
| 接管请求 | 橙色条「⚑ Bot 请求你接管：……」+ [接管并处理] | 遇到验证码、两步验证、需要登录时 |
| **交接卡片** ★ | 「⇄ 交接  A → B「任务名」  查看」 | 群聊和私聊里都可能出现 |
| **Bot 间私信卡片** ★ | 「✉ A 私信了 B（N 条）  展开」 | 展开后以只读方式内嵌显示对话 |
| **审批转发提示** ★ | 「⚑ Editor 在私聊里等待你审批  前往 →」 | 群里不显示审批卡片本身，只给一个跳转 |
| 正在回复 | 头像 + 「正在回复 …」 | 群聊里多个 Bot 同时回复时并排显示 |

**悬停在消息上**会出现：☺ 表情回应、↩ 回复（开线程）、⋯ 更多（复制、引用、存入记忆、删除）。

**滚动**：离开底部后出现「↓」回到底部按钮。新消息不会强行把视图滚下去，而是在按钮上显示数字。

### 3.4 输入框

- 胶囊形输入框：左边「＋」（附件、图片、截图），中间是输入区（`Shift+Enter` 换行），右边是发送按钮（以后加麦克风）。
- **`@` 弹出成员选择**：私聊里可以 @ 其他 Bot（相当于让它们私信协作）、群、定时任务；群聊里优先列出群成员和 `@everyone`。
- **`/` 弹出技能列表**：选择后插入一个技能标签。
- **Bot 运行时**，发送按钮变成「■ 停止」。此时仍然可以输入，新消息会**插入当前任务**（相当于中途纠正方向）。
- 占位文字：私聊为「给 X 侦察 发消息…」，群聊为「在 发布小组 发消息，@ 指定成员…」。
- 草稿按会话分别保存。

### 3.5 群聊专章 ★

群聊是 Mac Bot 的核心功能。界面上要让三件事一眼可见：**谁在说话、谁负责、Bot 之间在协作什么**。

**① 新建群聊**（`⌘N` → 勾选 2–6 个 Bot → 下一步）

```text
┌────────────────────────────────────────────────────────────────┐
│ 新建对话                                                ✕      │
│ ⌕ 输入名字新建 Bot，或选择成员建群                             │

│ ────────────────────────────────────────────────────────────   │

│ [✓] (C) Coordinator      协调                                  │
│ [✓] (E) Editor           内容                                  │
│ [✓] (A) Analyst          数据                                  │
│ [ ] (X) X 侦察           每日 X 科技侦察                       │
│ [ ] (P) 比价助手          购物比价                             │
│                                                                │
│                                  [取消]  [下一步：建群 (3)]    │
└────────────────────────────────────────────────────────────────┘
```

```text

│                                                                │

│ 绑定项目  [ # mac-bot ⌄ ]     （群内共享这个项目的记忆）       │
│ 成员      (C) (E) (A)   ＋                                     │
│                                                                │
```

**② 群头部**：叠放头像 + 群名 + 成员数 + 绑定的项目标签；第二行是「负责人：Editor ★」。点击群名，右侧面板打开「群信息」。

**③ 谁来回应（对应后端 PLAN 5.4 的路由算法，界面上的表现）**

| 你发的消息 | 谁回应 | 界面表现 |
|-----------|--------|----------|
| `@Editor …` | 只有 Editor | Editor 头像出现「正在回复」 |
| `@everyone …` | 所有成员 | 所有成员依次出现「正在回复」 |
| 对某条消息点「↩ 回复」 | 只有那条消息的发送者 | 右侧面板打开线程，回复在线程里进行 |
| 普通消息（没有 @） | 路由器挑选 0 到 n 个 Bot，默认倾向负责人 | 被选中的 Bot 出现「正在回复」。如果没有人认领，显示灰字「没有成员认领这条消息 · @ 指定」 |

**④ Bot 之间在群里协作**

- Bot 发言时可以 @ 其他 Bot，被 @ 的 Bot 接着回应。消息流里自然形成接力。
- **交接**：卡片「⇄ 交接 A → B「任务」」，同时出现系统事件「负责人变更为 B」，群头部的 ★ 移到 B。
- **Bot 间私信**：不在群里刷屏，以「✉ A 私信了 B（N 条） 展开」卡片的形式出现，展开后只读。
- **防循环**：同一条用户消息引发的 Bot 间往返超过 8 次后，出现横幅「⏸ Bot 之间已连续往返 8 次，已暂停」+ [再允许 8 次] [结束这一轮]。
- **审批不进群**：群里只显示「⚑ X 在私聊里等待你审批 前往 →」。
- 每个 Bot 的运行状态在右侧成员列表里实时显示（⟳ 运行 / 空闲 / ⚠ 等你）。

**⑤ 线程**（对任何消息点「↩ 回复」后，在右侧面板打开）

```text
┌──────────────────────────────┐
│ ‹   线程 · Analyst   »       │
│                              │
│ (A) 数据在 shared/metr…      │
│ ──────────────────────────   │
│ (E) 周活口径是 7 日？        │
│ (A) 是，7 日去重。           │
│                              │
│ ( 回复 Analyst… )            │
└──────────────────────────────┘
```

**⑥ 群信息面板**（右侧，群聊默认显示）

- 成员 N/6：头像、名字、★ 负责人、状态；「管理」可以添加或移除成员、设为负责人。
- 群目标：成员 Bot 每次回复前都会读取，可以编辑。
- **群备忘**：群里形成的决议（成员 Bot 用 `memory(scope=chat)` 写入，你也可以直接加），所有成员每轮都会读取。
- 绑定项目：群内共享这个项目的记忆，可以更换。
- 成员屏幕：每个成员浏览器的小缩略图，点击展开 Agent Computer。
- 共享文件：群里产生的文件。
- ⚙ 进入群设置：群名、目标、负责人、项目、通知、删除群聊（Bot 不会被删）。

**⑦ 群聊的边界**

- 群里的 Bot **仍然使用各自的模型、规则和 Bot 笔记**，额外读取群目标和绑定项目的记忆。
- 同一个 Bot 可以同时在多个群里；它的任务按 inbox 排队，同一时间只执行一个。
- 删除群聊只删除这个会话，不会删除 Bot 和项目记忆。

### 3.6 新建 Bot

1. `⌘N` → 输入名字 → 「＋ 新建 Bot「研究员」」，或者在面板里直接点「新建 Bot」，得到一个 New Bot。
2. **对话式引导**（Grok 的做法）：新 Bot 第一句话是「我主要应该帮你做什么？」。根据你的回答，它自己填好头衔和描述，然后给出建议：「要不要给我设一个定时任务？」「要不要关联项目 # mac-bot？」
3. 随时可以在右侧 ⚙ 设置里手动修改。

## 7. 服务端组件职责（与界面的对应关系）

| 组件 | 职责 | 驱动哪些界面 |
|------|------|-------------|
| Gateway | 一个端口；密码鉴权；`/ws` 双向事件流（带 seq，断线可以补发）；`/api/v1` HTTP；`/admin` | 所有客户端、管理页 |
| Bot Runtime | 每个 Bot 一个 actor 和一个 inbox；durable 执行（崩溃后可以恢复）；工具调用；审批挂起和恢复；插话；停止 | 私聊、工具活动、任务卡片、审批卡片、停止按钮 |
| **Orchestrator** ★ | 群聊路由（@、回复、路由器）、`@everyone`、Bot 间 @ 接力、`send_message`、`handoff`、负责人、防循环计数、把审批转到私聊 | 群聊全部界面元素 |
| Memory | 三层记忆的读写；会话开始时注入快照；`session_search` | 记忆页、Projects 页、个人画像 |
| Providers | 服务商和模型目录；流式输出；用量统计 | 模型设置、用量页、错误卡片 |
| Scheduler | 定时任务的计算和触发、试运行、运行记录 | 定时任务列表和编辑页 |
| Browser（agent-browser） | 每个 Bot 一个会话；观察和动作工具；画面流代理；接管时转发输入 | Agent Computer、屏幕缩略图、截图 |
| Store | SQLite（消息全文检索、事件日志） | 搜索、断线补发 |
| Admin / CLI | 密码、端口、状态、日志 | 管理页、终端 |

**客户端 ↔ 服务端的主要事件**（`/ws` 推送，供界面订阅）：

`message.created` · `message.delta`（流式）· `message.updated` · `activity.step` · `run.state`（运行 / 等你 / 空闲 / 出错）· `approval.requested` / `approval.resolved` · `question.asked` · `handoff.created` · `owner.changed` · `bot_dm.created` · `group.loop_paused` · `typing`（哪些 Bot 正在回复）· `screen.frame` / `screen.url`（订阅制）· `routine.run` · `memory.updated` · `host.status`

## 附录 A：Grok Bot 界面要点（参考来源）

从官方截图和文档整理：
- 三栏布局：侧栏 / 会话 / 右侧上下文面板。
- 侧栏有自定义分组、置顶头像磁贴、「Hidden Bots N」、底部的插件和用户菜单。
- 用户消息是黑色气泡，Bot 消息是浅灰气泡。
- 提问卡片用 A/B/C 选项，选完后显示 ✓。
- 任务卡片带「Running」状态和操作按钮。
- 右侧面板默认显示「X's screen」缩略图和 Routines 列表；⚙ 进入 Settings（Name、Title、Description、Notifications）；定时任务页有 Active 开关、Delete、Test run、Instruction、When to run（可以 Add another）、Run history。
- 电脑视图覆盖整个窗口，右上角是「Teach a task」和收起按钮。
- 群聊：2–6 个 Bot；不 @ 时由 Bot 自己决定谁回应；`@everyone` 少用；用回复形成线程；审批、密码请求和草稿不在群里出现；Bot 间私信出现在各自的会话里；群有 Group name 和 Description。
- 审批：Allow once / Always allow / Deny；规则分 Ask first 和 Allow automatically，冲突时 Ask first 优先。
