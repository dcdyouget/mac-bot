# v1.1 §5 Android long-press audit

- Existing behavior: long press opens a bottom action sheet with reactions, reply, reference, quote-to-announcement and trace navigation; exact timestamp is also shown in the sheet. Reply/reference protocol fields are sent by the composer.
- Fixed: copy now collects markdown text blocks (falling back to `fallback_text`), copy message link uses a `macbot://chat/...` route with `message_id`, and user-authored messages expose `message.delete`.
- Deep-link routing now preserves the optional message ID and opens the chat at that message. Parser tests cover valid message links and invalid/duplicate message IDs.
- Correction: host, chat and message identifiers are percent-encoded as URI components; delete failures keep the action sheet open and show a localized error.
