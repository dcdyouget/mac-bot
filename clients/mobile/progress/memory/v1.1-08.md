# v1.1 §8 Android message-block audit

- Existing `KnownBlockTypes` and `BlockView` use protocol `type` names directly: text, image, file, task_card, completion, progress, blocked, question, project_card, review_card, delegation, approval, approval_ref, takeover_request, bot_dm_ref, system, loop_paused and link_preview.
- Unknown/malformed block entries bypass block rendering and show a bordered warning populated from message-level `fallback_text`, with the localized update-client hint. No aliases or incompatible block names were found; no code change was needed.
