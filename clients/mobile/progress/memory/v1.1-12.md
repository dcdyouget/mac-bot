# Android memory v1.1 §12

- Replaced the profile route on Memory with an inline “关于你” card: name and identity save on blur/Enter, language offers system plus localized choices, unknown BCP 47 tags remain visible, and timezone is read-only. Fields use server-compatible Unicode scalar limits and explicit JSON null for clearing. A warning banner above the card exposes version conflicts and reloads the latest profile; save success fades in.
- Added a loading skeleton and source rows for curator, manual-user, and legacy bot entries. Curator rows link to their source chat and show `updated_at` in local time; bot rows show the bot avatar and name.
- Profile editing keeps drafts against the previous server snapshot, serializes writes, drops stale queued submissions, and rechecks profile events after a write finishes so remote updates cannot overwrite active text. Tests cover races, conflict reload, versioned null clearing, and source timestamps.
- Verification: `:shared:commonTest`, `:shared:androidUnitTest`, `:androidApp:testDebugUnitTest`, and `:androidApp:assembleDebug` passed with JDK 21 and Android SDK 36.
