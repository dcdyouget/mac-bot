# v1.1 §9 Android audit — free-text announcements

- Existing: announcement content is a single Markdown string, shown through the shared Markdown renderer; updates send `announcement.update` with a base version; conflicts expose latest text and offer load-latest or keep-draft actions. The mobile full-screen editor already has an 8,000-character limit, version/count, and Markdown controls.
- Corrected: the editor now requests focus when opened. Markdown controls normalize forward/reversed selection, prefix selected lines for heading/lists, and wrap selected text for bold/code/link while placing the caret or selection at a useful location. Quoted messages append to the draft while preserving cursor position. Saving consistently uses the text value and its conflict version.
- Tests: common tests cover reversed selection, multi-line prefixing, caret placement, and preserving selected text for code and links.
- Constraints: announcements remain Markdown text; member/status/artifact data are separate from the body. The renderer is existing shared functionality.
- Validation: Android common and unit tests plus debug assembly passed with the SDK environment variables recorded in v1.1-03 evidence.
